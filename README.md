# Jack Maguire - Modern Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and experience. Built with clean HTML, modern CSS with gradients and animations, and vanilla JavaScript.

## 🚀 Features

- **Modern Design**: Contemporary layout with gradient accents and smooth animations
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Elements**: Smooth scrolling, hover effects, and scroll animations
- **Project Showcase**: Elegant project cards with detailed descriptions
- **Admin Panel**: Password-protected admin interface for managing custom projects
- **Image Carousels**: Interactive image galleries for project showcases
- **Fast Performance**: Optimized for speed and accessibility
- **Mobile Menu**: Hamburger menu for mobile navigation
- **GitHub Pages Ready**: No server required, works with static hosting

## 📁 Project Structure

```
jack-maguire-portfolio/
├── index.html          # Main page
├── css/
│   └── styles.css      # All styling and animations
├── js/
│   └── script.js       # Interactive functionality
├── images/             # Project and personal images
├── documents/          # PDFs and documentation
└── HTML Pages/         # Individual project pages
```

## 🎨 Design Highlights

- **Color Scheme**: Dark theme with indigo/purple gradients
- **Typography**: Poppins font family for modern look
- **Animations**: Smooth transitions and scroll-triggered animations
- **Glassmorphism**: Frosted glass effect on cards
- **Responsive**: Mobile-first responsive design

## 📝 Sections

1. **Hero Section** - Introduction and call-to-action buttons
2. **About Me** - Background, interests, and skills
3. **Projects** - Featured projects with descriptions and links
4. **Education** - Educational background and certifications
5. **Footer** - Copyright and quick links

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations and gradients
- **JavaScript (Vanilla)** - No frameworks, pure JS for interactivity
- **Local Storage** - Browser storage for admin sessions and custom projects

## 🔐 Admin Panel

A password-protected admin interface for managing custom projects:

- **Authentication**: Session-based login system
- **Project Management**: Add, edit, and delete custom projects
- **Image Upload**: Support for project images
- **Data Persistence**: Uses browser localStorage
- **Security**: Basic password protection (change default password!)

Default admin password: `jackadmin123` (change this immediately!)

- **Google Fonts** - Poppins font family

- Tablet: 768px to 1199px
- Mobile: Below 768px
