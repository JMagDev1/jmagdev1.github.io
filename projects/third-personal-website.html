3rd Personal Website

A modernised portfolio with a dark indigo and purple theme, scroll animations, a rotating skills card and a searchable, filterable projects table.

  • 🌌 Dark Gradient Theme
  • ✨ Scroll Animations
  • 🔎 Filterable Projects

About This Project

My third personal website, a full redesign of the second one. It has a dark theme with indigo and purple gradients, frosted-glass cards and animations that play as you scroll.

The home page covers my skills, featured projects and education, and an All Projects page lets you search, filter by type and sort every project.

Key Features

  • Hero section with a rotating skills card
  • Scroll-triggered animations
  • Featured project cards
  • Education and certifications section
  • Projects table with search, type filter and sorting
  • Project pages with an image carousel
  • Mobile menu

Challenges & Solutions

Projects added through its admin panel were only saved in the browser's local storage, so they never appeared for anyone else. This site (the 4th version) fixes that by publishing new projects straight to GitHub.
