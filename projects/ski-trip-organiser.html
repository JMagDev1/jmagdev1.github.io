Ski Trip Organiser – GCSE Digital Technology

GCSE Digital Technology coursework: a C# program that helps a teacher assign pupils on a school ski trip to the right ski group.

About This Project

A coursework project for GCSE Digital Technology that demonstrates the ability to create a functional application addressing a real-world problem.

The brief was a school ski trip: the organiser needed a way to assign each pupil to a beginner, intermediate or advanced group, based on their dry ski slope times and a quiz on ski safety.

Key Features

  • Staff login screen
  • Adding pupil details
  • Ski safety quiz
  • Recording five ski slope times for each pupil
  • Average time and group level for each pupil
  • Reports: student list, quiz scores and group levels

Challenges & Solutions

The main challenge was understanding and implementing user requirements while maintaining clean code structure. Creating a system that was both powerful and user-friendly required careful planning.

What I Learned

This GCSE coursework project taught me how to approach a problem systematically, design solutions, implement them in code, and test thoroughly. I learned about user requirements and designing software to meet specific needs.
