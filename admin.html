Portfolio admin

Sign in with a GitHub fine-grained access token to add, edit and publish projects. The token is kept in this tab's memory only. It is never saved and is only ever sent to api.github.com.

You were signed out after 30 minutes of inactivity. Enter your token again to continue. Your unpublished changes are still here.

How do I create a token?
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it something like Portfolio admin and pick an expiry (90 days or less is sensible).
  3. Under Repository access choose Only select repositories and pick jmagdev1.github.io.
  4. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else as No access.
  5. Generate the token, copy it, and save it in your password manager. Paste it above whenever you want to edit the site.

Classic tokens (starting ghp_) are refused because they can reach every repository you own.

For security, the admin panel doesn't work when it's shown inside another page. Open jmagdev1.github.io/admin.html directly to sign in.
